BẮT ĐẦU CÙNG CODE DESK.

Tiện ích cộng đồng của Củ Cải Phẫn Nộ, giúp nhập lần lượt giftcode trên trang Garena Delta Force, theo dõi kết quả và nhớ code đã xử lý. Bản miễn phí tải qua GitHub, dùng trên Chrome máy tính.

01

Cài từ thư mục đã giải nén

  1. Tải file Garena-Code-Desk-v1.2.3.zip từ trang phát hành, giải nén vào thư mục cố định.
  2. Nhập chrome://extensions vào thanh địa chỉ Chrome, bật Chế độ dành cho nhà phát triển / Developer mode.
  3. Bấm Tải tiện ích đã giải nén / Load unpacked, chọn thư mục extension chứa manifest.json.
  4. Bấm biểu tượng mảnh ghép để ghim Code Desk. Giữ nguyên thư mục đã nạp.

Ở phần Assets của GitHub, chọn đúng ZIP đã đóng gói theo tên trên. “Source code” là bản chụp toàn bộ repository do GitHub tự tạo. Xem hướng dẫn của Chrome ↗

02

Đăng nhập và bắt đầu ngay trên Garena

Mở trang đổi quà Garena, đăng nhập tài khoản game và kiểm tra đúng tên tài khoản. Trong khung Code Desk ở góc trang, bấm Bắt đầu. Có thể Dừng, Tiếp tục và thu gọn tại chỗ.

Đăng nhập tài khoản Google trên Chrome là phiên riêng, không thay cho đăng nhập Garena. Code Desk không yêu cầu bạn nhập mật khẩu game vào tiện ích.

Bạn có thể dùng tab hoặc ứng dụng khác. Giữ Chrome, tab Garena mở và máy đang thức. Nếu gặp CAPTCHA hoặc hết phiên, hoàn tất trực tiếp trên Garena rồi tiếp tục.

03

Lấy code mới hoặc thêm danh sách

Trong popup, Quét nguồn & đổi ngay sẽ quét nguồn rồi mở lượt đổi. Muốn tự chọn thời điểm, mở bảng quản lý, dùng Quét nguồn ngay để tự lưu code mới vào hàng chờ. Dòng kết quả báo số mã vừa thêm; nút Xem code mới và bộ lọc Mới từ lượt quét giúp xem riêng lượt vừa quét. Không cần bấm thêm lần nữa. Bạn cũng có thể dán danh sách tại Thêm code của bạn, mỗi dòng một code. Có thể chọn file TXT, CSV hoặc JSON.

Lịch quét mặc định 09:00 giờ Việt Nam. Quét xong, tự mở Garena và đổi code mới là tùy chọn riêng, mặc định tắt. Code trong ảnh, video và bình luận cần nhập bổ sung; bộ quét hiện đọc nguồn chữ công khai.

Bản 1.2.3 quét mặc định XemGì, tin Garena và Code Mới. Cập nhật sẽ tự thêm Code Mới nếu chưa có; nguồn đã được anh em tự thêm và tắt vẫn giữ nguyên. Trong Thêm nguồn, có gợi ý Download.com.vn và Điện máy XANH; chọn nguồn rồi bấm Cấp quyền & thêm nguồn. Nút Dán 8 mã khảo sát · 25/10 chỉ là cách nhập dự phòng; quét thành công đã tự lưu mã mới. Nếu nguồn lỗi hoặc đổi bố cục, kết quả báo rõ nguồn chưa đọc được.

04

Đọc bộ đếm và kết quả

  • Đã xử lý: số code đã xử lý trong lượt hiện tại.
  • Còn chờ: code chưa gửi trong hàng chờ của tài khoản.
  • Đã nhận / Bỏ qua: kết quả đã lưu trong lịch sử tài khoản hiển thị.
  • Lỗi cấu hình gói quà: bỏ qua code đó và tiếp tục các code khác; không tự thử lại.
  • Kết quả chưa rõ: bỏ qua code đã gửi, lưu phản hồi và không tự thử lại; không tự xem là đã nhận quà.
  • Dữ liệu cũ: code đang chờ thử lại, chưa mở đổi hoặc cần kiểm tra được chuyển sang Đã bỏ qua khi cập nhật 1.2.3.
  • Đăng nhập, CAPTCHA, giới hạn tốc độ hoặc lỗi kết nối: bỏ qua code đã gửi và tạm dừng lượt. Xử lý trên Garena rồi tiếp tục các code còn lại; với HTTP 429 chờ ít nhất 15 phút.

Dùng tìm kiếm và bộ lọc trong Danh sách & kết quả để xem chi tiết. Code tìm thấy là ứng viên; hiệu lực và quyền nhận quà do Garena quyết định.

05

Cập nhật và hỗ trợ

Bấm Dừng, chờ code đang gửi có kết quả. Tải ZIP mới, chép nội dung extension vào đúng thư mục cũ, bấm Tải lại trên thẻ tiện ích, kiểm tra phiên bản 1.2.3 rồi tải lại trang Garena. Bản 1.2.3 thêm quyền đọc codemoi.net để quét nguồn mới; nếu Chrome yêu cầu xác nhận quyền, kiểm tra đúng tên miền này. Bản cài từ thư mục cập nhật thủ công.

Khi kiểm tra lại lỗi CSP, xóa báo cáo cũ trong mục Lỗi của tiện ích rồi mới chạy lượt mới. Báo cáo cũ có thể vẫn nằm trong danh sách sau khi cập nhật.

Gửi lỗi tại GitHub Issues kèm phiên bản và thông báo. Issues là nơi công khai; chỉ chia sẻ phần cần thiết, tránh mật khẩu, cookie, OTP và token.

ẢNH

Nhận diện các nút trong bản mới

Các ảnh dưới chụp lại từ bản 1.2.3, dùng đúng mã giao diện tiện ích với dữ liệu mẫu. Chúng là bản xem giao diện, chưa phải ảnh xác nhận đã cài hoặc đổi quà trên tài khoản thật.

BẢN THỬ NGHIỆM · Kiểm tra logic và trình duyệt giả lập không thay cho việc đổi quà trên tài khoản Garena thật. Không bảo đảm mọi code còn hiệu lực. Tên hiển thị được dùng để phân lịch sử; tài khoản trùng tên nên dùng hồ sơ Chrome riêng.
